# Kira UUI / Unified – historisches Entwicklungsarchiv

Dieses Repository archiviert drei getrennte Entwicklungsreihen:
`UUI_CORE`, `UUI_BRIDGE` und `KIRA_UNIFIED_CORE`.
In `modules/` steht jeweils der zuletzt importierte Stand jeder Reihe.
Alle frueheren Staende sind ueber die unten genannten **Git-Tags** erreichbar.

**Chronologie:** Innerhalb jeder Reihe nach Versionsnummer sortiert;
die Reihenfolge **zwischen** den Reihen ist eine Importreihenfolge,
keine nachgewiesene historische Zeitleiste. Die Git-Datumsangaben sind Importdaten.
Der Import allein belegt keine Lauffaehigkeit oder Integration.

Die separat vorliegende `KIRA_Roadmap_2_1_Origin_Life_Experience.docx`
wurde nicht automatisch aufgenommen und muss vor einer Veroeffentlichung
gesondert auf persoenliche Angaben und Rechte geprueft werden.
